The Midden

A refuse heap, read as a record. Drop an export in and it counts what accumulated — the words that keep coming back, when they arrived, and which conversations turn out to be the same conversation.

What it eats
claude.ai
Settings → Privacy → Export data. Mail arrives with a .zip; drop the zip whole, or the conversations.json inside it.
Claude Code
~/.claude/projects/<slug>/*.jsonl — drop one file, many, or the folder.
ChatGPT
conversations.json from its export zip.
Raw
Any JSON array of {role, content} messages.

This page makes no network requests of any kind. There is no API key because there is no API: the themes are computed from word statistics, right here, in about a second. That has limits, and the Themes panel says what they are.
